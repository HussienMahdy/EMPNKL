# قاعدة بيانات إدارة نخل التعليمية

## التشغيل
1. افتح `index.html` في المتصفح، أو ارفع المجلد إلى مستودع GitHub وشغّل GitHub Pages.
2. من الصفحة اختر ملف Excel من جهازك.
3. اختر ورقة البيانات المطلوبة، ثم استخدم البحث والفلاتر.
4. يمكنك تصدير النتائج المطابقة إلى CSV.

## الخصوصية المهمة
الموقع يعالج ملف Excel داخل المتصفح ولا يرسل محتواه إلى خادم أو يضمّن البيانات في ملفات الموقع. ارفع ملف التطبيق فقط إلى GitHub، ولا ترفع ملف Excel الأصلي أو نسخة JSON من بيانات الموظفين إلى مستودع عام؛ قد يحتوي الملف على أرقام قومية وبيانات وظيفية.

## ملاحظة
الفلاتر الخاصة بالمدرسة والتخصص والمرحلة والمادة تتصل تلقائيًا بالأعمدة التي تتعرف عليها الصفحة. إن لم يوجد عمود مستقل للمرحلة في الورقة، يبقى البحث العام متاحًا في جميع حقولها. جميع الأعمدة غير الفارغة في الورقة المختارة تظهر في الجدول.
